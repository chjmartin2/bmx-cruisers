# BMX Cruisers 1.2.0 for Windows

All five original courses, one life to earn a high score, and unlimited practice. This release improves the park, celebrations and feedback when a ride goes wrong.

- Continuous grass-to-water shorelines on every course, with sloping wet banks and shoreline dressing following the curves.
- Vivid, oversized fireworks with bright heads, colored trails and sparkling embers.
- A visible crash reaction: an impact flash, rider fall and dust, or water spray and splash rings. Results appear after a 1.8-second hold; movement and score stop at impact.
- Restored solid bridge guardrails and posts, aligned with the rendered timber. All cosmetic rides keep the same collision footprint.
- A solid dark-gray status bar and controller-aware hints. Xbox Menu/Start pauses and resumes; View/Back returns to the main menu and ends an active one-life run.

Normal retains the recovered PAL movement and native course timing. Modern contacts follow the displayed rider and scenery. Practice, customization, five pace settings, adjustable camera, 1080p/4K scene detail and the guitar-based soundtrack remain included.

## Install

Extract the complete Windows x64 ZIP and run **BMXCruiser.exe**. Keep its Engine and BMXCruiser folders together. Unreal Editor is not required. Instructions, credits, licenses, release notes and a file manifest accompany the download; SHA-256 is in SHA256SUMS.txt.

## Verification and limitations

Native simulation checks cover all five courses and original timing. Display checks cover 1080p, 4K, DPI and window bounds. Packaged checks cover land/water crash reactions at several paces, a 4K crash, bridge guardrail contacts on all five courses, clear-lane probes and a recorded guardrail strike. The existing rendered full-campaign input fixtures predate the guardrail repair and clip restored rails; they are not counted as a 1.2 full-campaign replay pass.

This remains a Windows development build with limited hardware coverage. Rider animation, some materials and close garage shadows can improve. Target: Windows 10/11 x64 and a DirectX 12 / Shader Model 6 capable GPU. No iOS, macOS or multiplayer build is included.

The [version 1.2 trailer](https://www.youtube.com/watch?v=GMSA1Eg3nrI) opens with authentic C64 emulator gameplay and transforms into the Windows course. It shows the five courses, Practice, six ride styles, controls, camera options and finish celebrations. The release includes 4K and 1080p MP4 downloads and trailer checksums. The original Windows ZIP is unchanged.

Original BMX Racers: David Darling and Richard Darling, Mastertronic. This is an unofficial recreation. Full third-party acknowledgements are included.
