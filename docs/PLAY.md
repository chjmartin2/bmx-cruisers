# BMX Cruisers — five-course Windows build

Extract the entire folder and run BMXCruiser.exe. Keep the Engine and BMXCruiser subfolders beside it. Unreal Editor is not required. If the Microsoft runtime is missing, run Engine/Extras/Redist/en-us/vc_redist.x64.exe.

Target: 64-bit Windows 10/11 with a DirectX 11 / Shader Model 5 capable graphics device. An integrated GPU can use the new Performance preset; a discrete gaming card, DirectX 12 and ray tracing are not required. Hardware minimums remain provisional until tested on a wider range of PCs.

Version 1.3 starts in Performance: up to a 900p scene with temporal reconstruction, a sharp full-resolution interface, reduced decorative density and a 60-fps limit. Settings > Graphics offers Performance, Balanced (up to 1080p with conventional shadows) and High (more decoration, 1080p or optional 4K). Changing Graphics on the start-screen settings page reloads the selected course. No graphics setting changes speed, collision, course layout or scoring. Use Performance on laptops and older computers. Keep the laptop plugged in for the best performance.

Press F11 for single-monitor fullscreen. The window/interface size is independent of scene detail. Keys 1/2 select the High preset's 1080p/4K preference; they do not raise the Performance or Balanced rendering budget.

Select Play Game for a one-life run from Course One through Course Five. A crash ends the game. Continue after each finish to keep the run alive. Only completing all five courses in order on the same pace qualifies for the High Score Board. R abandons a game and starts again at Course One; pace is fixed during a game.

Practice Courses lets you choose and retry any course without a lives limit. Practice scores never enter the High Score Board. Existing practice records are retained separately; older retry-based records do not qualify for the new board.

Arrows/WASD, the controller D-pad or the left analog stick move and steer. P/Escape pauses, R retries. Xbox Menu/Start pauses and resumes; View/Back returns to the main menu, ending an active one-life run. Keyboard menus use Up/Down/Tab, Left/Right and Enter; Escape returns. The controller D-pad and A/B navigate menus, and control hints follow the input device being used. C opens Camera View; Page Up/Down adjusts tilt, +/- changes distance and Home resets it. M/V toggles music/effects. F9 saves a screenshot.

Normal retains each course's native PAL timing, including the original increase in scroll speed between courses. Other paces multiply that native speed. Lateral steering stays responsive at the same real-time rate across the five pace options. Rider/equipment choices affect appearance only.

This build includes all five original course layouts, scenery and finish celebrations, course selection and continuation, separate course/pace records, overall score records, saved customization and camera settings. Existing Course One best scores migrate automatically.

Contacts follow the displayed rider, smooth shorelines and visible obstacles. Bushes have inset boundaries so grazing leaves is more forgiving. Decorative trail wear, litter and shoreline pebbles do not cause crashes. Every ride style uses the same footprint. A short Get Ready interval lets the course settle before the race clock begins.

A crash ends the current attempt immediately. An impact flash, fall and dust burst (or water spray and splash rings) remain visible for 1.8 seconds before the result menu appears. Score and movement stop at impact; controls cannot skip the reaction or accidentally restart from a held button. Practice provides unlimited selected-course retries; Play Game keeps the original one-crash frustration. Rider animation and some materials/shadows remain beta quality. This is a Windows development build; iOS, macOS and multiplayer are not included.
