# BMX Cruisers 1.0 beta

Download **BMX-Cruisers-1.0.0-beta.1-Windows-x64.zip** from the GitHub release, extract the entire folder, then open **BMXCruiser.exe**. Unreal Editor is not required to play. Keep the Engine and BMXCruiser subfolders beside the executable. If Windows reports a missing Microsoft runtime, run the included Engine/Extras/Redist/en-us/vc_redist.x64.exe.

Target: 64-bit Windows 10/11 and a DirectX 12 / Shader Model 6 capable GPU. Begin at 1080p; 4K scene detail is optional. A minimum GPU/VRAM specification has not been established across a hardware test matrix. The download is an unsigned development beta.

Press Enter through the intro and choose Ride Course One. Arrows or WASD steer; Up/Down moves within the view. Escape/P pauses, R restarts, F11 toggles fullscreen. Use Up/Down/Tab to select menu rows, Left/Right to change a setting and Enter to confirm. C opens Camera View; Page Up/Down and +/- adjust the live camera; Home resets it. M/V toggle music/effects. F9 saves a screenshot.

Normal is the original PAL simulation rate. Cruise, Relaxed, Fast and Expert change course pace to 65%, 80%, 120% and 140%, while lateral steering stays at Normal's real-time rate. Scores are separate for each pace. Appearance choices do not change collision, scoring or difficulty. Use Customize Character for boy/girl, skin tone, clothing, helmet/vehicle color and cruiser/BMX/scooter/inline skates/quad skates/wheelchair.

This beta includes one complete course. The other original courses and mobile ports are not implemented. Shoreline smoothing is visual; the original collision masks decide whether a ride crashes. Finish effects and wildlife are decorative.

Original game: BMX Racers, David Darling and Richard Darling, Mastertronic. This is an unofficial recreation, not an official Mastertronic release. See CREDITS.txt and THIRD-PARTY-NOTICES.txt in the download for asset and engine acknowledgements.
