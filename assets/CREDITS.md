## Garage art pass / 0.4

The inline boots/wheels, quad boots/trucks/toe stops and stunt scooter frame/wheels are authored multi-material meshes generated by `tools/author_equipment.py`; source OBJ/MTL files and mesh inventories are in `assets/source/workshop`. They use centimetre-scale dimensions and separate leather, molded shell, woven liner, laces, stitches, alloy, polyurethane and grip surfaces. No outside equipment models were downloaded.

YoungRiderV2 and YoungGirlV2 are MIT Rocketbox derivatives: one Loop subdivision refines the face/hand/body silhouette and interpolates the original skin weights, UVs and material assignments. `tools/refine_riders.py` records this process; the original Microsoft source files remain untouched. These are refined versions of the existing avatar models, not photogrammetry scans or MetaHuman characters. Original MIT notices remain applicable. New skin-tone controls, masked sportswear materials and foot-equipment animation are authored additions.

Angular racing menus use the existing cover-inspired artwork and Unreal's bundled Roboto fonts. The non-repeating trail treatment combines rotated/macro-blended scanned materials with course-specific cracks, repairs, wear lines and dusty verges. None of these changes modify the recovered game code, route or collision data.

## Detailed head / skin materials

The current rider head uses a baked neutral mesh from the locally installed Unreal Engine 5.8 MetaHuman character template, Epic Games. The bake is 61,978 triangles; creator services, DNA runtime and facial animation plugins are not used by the packaged game. Reference pores were exported from the installed identity-template normal texture. The technical UV guide is preserved as reference only and is not used as skin color.

The male/female skin albedo atlases were authored with the built-in image-generation tool against that UV guide. Selected PNGs and complete prompts are in `assets/source/hero`. Runtime skin palettes tint the skin materials independently of clothing/hair. Eye color/iris detail is authored procedurally in the material. The body remains a refined, skinned Microsoft Rocketbox derivative with authored clothing and equipment; the rider is not a complete assembled MetaHuman.
